dgamelaunch / SSH terminal

floatingeye.net

Public Floating Eye NetHack terminal login service, hosted on Illithid.

To play, open a terminal or SSH client and connect with ssh nethack@floatingeye.net. Some browsers do not know how to open SSH links, so use the command directly if the link does nothing.

ssh nethack@floatingeye.net
