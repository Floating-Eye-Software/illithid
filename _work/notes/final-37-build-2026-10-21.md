## Merge Decisions

Only three files had textual conflicts:

- `include/config.h`: retain name-based scores (`PERS_IS_UID 0`) for shared
  dgamelaunch Unix accounts. Retain 1,000 total entries and 10 per player.
- `src/botl.c`: use upstream's exported `get_strength_str` and status code;
  upstream now defines `BOTL_NSIZ` as 16 in `include/botl.h`, preserving
  the Floating Eye name-length behavior without a duplicate definition.
- `DEVEL/hooksdir/nhsub`: accept upstream's prefix validation and remove
  obsolete commented debugging alternatives.

The 37-file remaining delta against upstream retains QueerHack, PetHack,
gluten conduct, launcher metadata, mail, server policy, build hints, and
variant documentation. This is a source-presence review, not a full
behavioral patch-disposition audit or regression test.

The existing post-checkout hook could not locate `NHgithook.pm` in a linked
worktree. Git operations used a command-scoped `core.hooksPath=/dev/null`;
repository hook configuration was not changed.

## Build Commands

From the integration worktree:

```sh
sh sys/unix/setup.sh sys/unix/hints/floatingeye
make fetch-lua
make -j1 all
./src/nethack --version
```

For a fresh build, check out merge commit
`df68139c3040dcabd8257a6f6c72ef6f2aeea592` and run the commands above.
The commit tree matches the recorded resolved index tree.

An initial `make -j4 all` raced recursive Lua builds, causing a truncated
archive. Recovery was `make -C lib/lua-5.4.8/src clean`, then the serial build
above. Use `-j1` with these makefiles. The successful build emitted 14
ignored-return-value warnings in the upstream Unix/file/recovery code; it
completed with no compilation or link errors. Upstream merge changes also
contain whitespace diagnostics; unrelated upstream formatting was retained.
